# Release v1.0.3

- **Date:** 2026-09-04
- **Candidate:** `qa_v1.0.3` (from `dev_v1.0.3`), QA green on `qa`
- **Production tag:** `v1.0.3` (code-only; documentation lives on `dev`/`main`)

## Overview

The v1.0.3 wave finishes the treatment-less ("Other") visit end to end, gives
dentists their own profile, puts pricing under admin control, and polishes the
booking and availability screens: billing prices dentist-entered work, receipts
show what was done, every save confirms in a sub-window, and empty states speak
plainly instead of rendering blank.

## Features in this release

**Treatment-less visits, end to end**
- Completing an "Other" visit requires the dentist's price, stored on the
  appointment (GAP-DEN-13)
- Reception bills it at that price; receipt, billing list, day view and slip
  name the patient's stated reason (GAP-REC-13)
- Finished-visit info shows the dentist's description on the patient's own
  receipt views only (GAP-PAT-30)

**Dentist portal**
- "My details" profile: read-only with an Edit control for name, specialisation
  and phone; fee view-only; phone editing moved here off availability (GAP-DEN-14)
- Profile states the configured revenue share as a rate (GAP-DEN-15)
- Schedule patients render as expandable cards, first open (GAP-DEN-12)
- Availability leads with day totals, open pills and Full markers; "Upcoming
  appointments" heading (GAP-DEN-16)

**Admin portal**
- Pricing tab: dentist share % and service charge, validated, live for the next
  bill with no restart (GAP-ADM-10)
- Reception handling metric removed from Reports dashboard and CSV export

**Booking and public page**
- No-doctors message instead of blank booking entries (GAP-PAT-31)
- Dentist cards render whole with even grey bodies; sub-threshold rating hint
  hidden (public polish)
- Register search card compacted; sign-in/sign-up accents moved to blue

**Platform**
- Every remaining update point confirms in a success sub-window (FTB-14)
- Success-sub-window and expandable-card patterns shared across roles

## What is not in this release

- Dentist profile photos / patient-facing dentist avatars (tracked as
  GAP-PAT-13 / GAP-DEN-07, specified not yet built)
- Older open gaps (GAP-PAT-04/05/06, GAP-REC-06, GAP-DEN-03/04, GAP-ADM-02..05)
